# Security Policy

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature:

https://github.com/bundasht/barony-save-watcher/security/advisories/new

Do not disclose security vulnerabilities, save files, filesystem contents, or
other personal data in a public issue. Include only the minimum reproduction
details needed to understand the problem.

Public issues are appropriate for ordinary bugs that do not involve security
or private data.
